# lloyd-dashboard-data

Private history for David's daily morning dashboard.

- `data/history.json` holds one row per day for each panel (share prices, GitHub stars and new repos, NICE publications, GP news counts, ICB page-change log, claims ledger). Each daily run appends to it, so the trend charts fill in over time.
- The page template and build script live in `davidlloyd73-cell/scratch`, folder `dashboard/`.
- No patient information and no SleepWell figures belong in this repo.
